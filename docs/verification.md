# 验证记录

2026-10-22，Node 24，Playwright + Chromium。

- 规则单元测试9项通过：正常移动与轮流、上方梯子、前进两格、所有其余特殊格、终点截断与胜利、1/4人轮流、白与月位置、无效存档、非法骰子点数与人数。
- 浏览器交互检查：真实骰子完成回合、双方轮流、刷新恢复棋子、重开确认与取消、4人棋子不重叠、两棋盘切换、白/空格/月点击内容、放大及返回、获胜后禁用骰子。
- 响应式检查：1440px桌面、390px手机，生成并人工查看完整页面截图；320px窄屏无横向溢出。放大棋盘允许内部横向滑动。
- 动画检查：普通动画模式下掷骰子时锁定重复掷骰、换棋盘与改变人数，完成后只增加一个回合；系统减少动态效果设置下同样能完成回合。
- 路线显示开关以实际SVG可见性验证，修复了SVG的hidden属性不能按HTML方式赋值的问题。
- 浏览器未捕获运行时异常。独立只读代码审查未发现额外严重问题。

本机复用已安装的Chromium进行验证时，设置PLAYWRIGHT_CHROMIUM_EXECUTABLE指向本机可执行文件；其他环境默认使用Playwright安装的浏览器。
