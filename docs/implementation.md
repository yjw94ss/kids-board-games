# 两张亲子棋盘网页游戏

用户已确认：同屏2人轮流掷骰子，可选1–4人；沿路线到终点；识字棋朗读汉字、自动执行前进提示与梯子。使用修正后的棋盘图，顶排为千、万、空、海、白、起点，底排明后为月。

使用原生HTML/CSS/JavaScript，静态发布至用户yjw94ss的独立GitHub仓库并启用GitHub Pages。不使用外部运行依赖或登录。项目保存在games/kids_board_games。界面采用Organic方向：鼠尾草绿、沙色、陶土色，棋盘为主体。

## 文件职责

- board-data.js：将图片格子映射为有序路线及特殊格。
- engine.js：纯函数处理轮流、落格、特殊移动、胜利和存档校验。
- app.js、index.html、styles.css：响应式游戏界面、动画、朗读与存档。
- assets/：两张棋盘图。
- tests/engine.test.js：走棋规则与存档校验。
- tests/browser.mjs：桌面/手机端交互、刷新恢复、切换棋盘、获胜与无横向溢出校验。

## 执行顺序与验证

1. 先编写规则测试并确认失败，再实现engine.js与board-data.js；验证起点、正常移动、前进、梯子、终点截断、轮流以及非法存档。
2. 实现棋盘图上透明格子按钮、四种棋子、骰子、状态栏、玩家数设置、规则说明和汉字朗读。动画期间禁用会改动游戏的控件，刷新只恢复完整回合。
3. 运行npm test与真实浏览器桌面/手机测试，目视检查截图。
4. 创建专用公开仓库kids-board-games，推送代码，启用GitHub Pages，等待发布成功并验证线上页面和资源。

## 路线约定

快乐点数棋采用47格完整蛇形路线，左上为起点，左下为终点，网页绿色/陶土色端点标识优先于原画装饰。识字棋从右上起点沿路线到左下终点，空格与花朵、火把是普通格；梯子从上方空格至江、下方空格至秋。落入前进格或梯子只触发一次，不递归触发；掷骰子到达或超过终点均获胜。
