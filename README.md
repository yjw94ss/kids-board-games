# 一起走棋 · 亲子棋盘

两张照片棋盘的网页游戏版本：快乐点数棋、经典飞行棋（第三册）。支持手机与电脑、同屏1–4人、掷骰子逐格移动、汉字及动物朗读、自动保存棋子位置、放大棋盘和重新开始。

## 本地运行

需要 Python 3 提供静态服务器（游戏本身没有服务端）。

```sh
npm run dev
```

打开终端输出的本地8126端口地址。源代码采用原生JavaScript，启动时自动打包为单个传统脚本game.js，无运行时第三方依赖。修改app.js、board-data.js或engine.js后运行 `npm run build` 更新game.js；发布时一并提交它。

## 检查

```sh
npm ci
npm test
npm run test:browser
```

浏览器测试使用Playwright Chromium，需要本机已安装或执行 `npx playwright install chromium`。测试前先运行静态服务器。

## 游戏规则

- 默认两人同屏轮流，可选一人练习或三、四人。无需投出特定点数即可出发。
- 快乐点数棋：沿47格完整蛇形路线，从左上到左下；绿色起点与橙色终点标识优先于原画中的装饰旗帜、奖杯。
- 经典飞行棋：从右上起点走到左下终点；顶排左至右为千、万、空格、海、白、起点；明右侧是月。
- 前进格按文字额外前进，上梯子由上排空格至江，下梯子由下排空格至秋；每次落格只触发一次。花朵、火把为普通格。
- 到达或超过终点均获胜；掷出6点不另加回合。同格可以容纳多人。

用户提供图片未附完整纸面玩法，以上是经确认的网页版规则。语音使用浏览器SpeechSynthesis，中文发音可用性取决于设备。存档保存在当前浏览器，不跨设备同步，也不提供远程联机。

## 发布

GitHub Pages直接发布main分支根目录，无需构建。棋盘图片由用户提供的照片参照重绘；游戏不上传原截图或本地个人资料，不收集用户数据。
